# Пин.

**Arduino без кода** — лёгкий блочный редактор для Arduino Uno. Программа собирается
из понятных блоков, готовый скетч обновляется на лету, а проверить логику можно на
виртуальной плате — без подключения железа.

**Открытый исходный код**  Без сборки и зависимостей


## Что умеет

- 10 простых блоков: пины, пауза, кнопка, датчик, повтор, серво, звук и Serial.
- Вложенные блоки и необязательная ветка «иначе».
- Перетаскивание мышью или пальцем, добавление блока нажатием.
- Живой скетч Arduino с подсветкой кода — его можно скопировать или скачать.
- Виртуальная плата: светодиод на пине 13, состояния пинов, серво, звук,
  кнопки, датчики и Serial-консоль.
- Настоящий монитор Serial через Web Serial в Chrome или Edge.
- Автосохранение проекта в браузере. Интернет не нужен.

## Быстрый запуск

### Windows

1. Дважды щёлкните **`start.bat`**.
2. Браузер откроет <http://127.0.0.1:8765/>.

Для запуска нужен Python 3. Если его нет, установите с
[python.org](https://www.python.org/downloads/) или просто откройте `index.html` —
редактор и виртуальная проверка работают и без сервера. Сервер нужен только для
удобного адреса `localhost` и монитора Serial.

Не закрывайте окно с сервером, пока работаете с приложением.

### macOS и Linux

```bash
cd pinblocks
python3 -m http.server 8765
```

Затем откройте <http://localhost:8765/>.

## Первая программа

1. Нажмите на блок **«Мигать»** в левой палитре — он появится в программе.
2. Поменяйте пин, количество повторов или паузу прямо в блоке.
3. Откройте вкладку **«Проверка»** и нажмите **«Запустить»**.
4. Посмотрите, как ведёт себя виртуальная плата.
5. На вкладке **«Код»** появится готовый скетч Arduino.

Блоки можно перетаскивать за ручку слева. Чтобы вложить действие в условие или
цикл, перетащите его внутрь блока. Условия «Если кнопка» и «Если датчик»
поддерживают ветку **«иначе»**.

## Как загрузить на плату

1. Нажмите **«Скачать .ino»**. Сохранится файл `uno_sketch.ino`.
2. Откройте его в [Arduino IDE](https://www.arduino.cc/en/software). Если IDE
   предложит создать папку для скетча — согласитесь.
3. В меню **Инструменты → Плата** выберите **Arduino Uno**, затем укажите порт.
4. Нажмите **«Загрузить»** (кнопка со стрелкой вправо).
5. Готово — плата выполняет программу.

Вся настройка пинов, `Serial.begin(9600)` и подключение серво уже добавлены в
скетч автоматически.

## Монитор Serial

Вкладка **«Плата»** умеет показывать Serial прямо в браузере:

- нужен **Chrome** или **Edge** (Web Serial API);
- сначала закройте монитор порта в Arduino IDE, иначе порт будет занят;
- нажмите **«Подключить»** и выберите плату в системном окне.

При подключении плата перезапустится — это нормально.

## Блоки

| Блок | Что делает |
| --- | --- |
| **Включить пин** | Подаёт HIGH или LOW на цифровой пин |
| **Мигать** | Включает и выключает пин заданное число раз |
| **Яркость** | ШИМ-яркость 0–100 % на пинах 3, 5, 6, 9, 10, 11 |
| **Пауза** | Ждёт указанное число секунд |
| **Если кнопка** | Проверяет кнопку на пине (используется `INPUT_PULLUP`) |
| **Если датчик** | Сравнивает аналоговый вход A0–A5 с порогом |
| **Повторить** | Повторяет вложенные блоки |
| **Серво** | Поворачивает сервопривод на угол 0–180° |
| **Звук** | Воспроизводит тон заданной частоты и длительности |
| **Serial** | Выводит текст или значение датчика в Serial на 9600 бод |

## Важно

- Приложение собрано под **Arduino Uno** и использует логику 5 В.
- Виртуальная проверка показывает логику программы, но не заменяет электрический
  расчёт. Проверяйте полярность и ток перед подключением.
- Серво и другие мощные нагрузки лучше питать отдельно, с общим проводом (GND) с
  платой. Не питайте их от пина 5 В при большом токе.
- Проект хранится локально в браузере. Очистка данных сайта удалит сохранённую
  программу.
